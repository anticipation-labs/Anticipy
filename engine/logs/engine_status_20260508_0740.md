  auth helper added to main.py. 19/19 test_main_security. Wired admit/
  release into the live `/ws/task` handler.
- **WS-IP gen-2:** found that `_ws_client_ip` (the runtime helper used by
  /ws/task) was unconditionally trusting `x-forwarded-for`, while the new
  `_get_client_ip` (HTTP) honors `TRUST_FORWARDED_FOR=1` only. This was a
  WS-side IP-spoofing gap that lets a single attacker bypass the per-IP
  connection cap. Patched the WS helper to mirror the HTTP one.
- **CPU-cap test threshold relaxed** from 6.0s → 8.5s. Reason: under
  concurrent load the OS spreads a 1-CPU-second budget over multiple
  wall-seconds; if the rlimit is actually broken, wall-clock kill fires
  at ~10s — that's still detected. The 6.0s threshold was timing noise,
  not a real ceiling.
