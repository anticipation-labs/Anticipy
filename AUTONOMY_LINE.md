# THE LINE — what Anticipy does on its own vs checks with you first

> Drawn together (Omar + agent). This is the "prerogative" — the single policy the engine enforces so
> the agent acts confidently where it should and pauses where it must. Email is just one row; the point
> is the WHOLE day, any system. Move any line; this is a starting proposal, not a decree.

| Category | Proposed default | Why | Your call |
|---|---|---|---|
| **Money / payment / transfer** | **ALWAYS ASK** (hard-locked, every mode) | irreversible, the one cardinal money rule | locked |
| **Sending to a person** (email/text/DM/reply) | **Prepare it fully → "ok to send?"** | reaches someone else; reversible until sent | ? |
| **Reversible web tasks** (look up, find, cart-no-buy, fill-to-review, research) | **JUST DO IT** (tell-me-to-stop) | reversible, no one else affected | ? |
| **Scheduling / calendar / reminders** (your own) | **JUST DO IT** | your own time, reversible | ? |
| **Replying/acting in your name to others' requests** | **Draft → confirm** | your voice/reputation | ? |
| **Anything irreversible / destructive** (delete, cancel, submit-final) | **ALWAYS ASK** | can't undo | ? |
| **Reading / scraping your own accounts** (onboarding, context) | **JUST DO IT** (read-only) | learning you, no side effects | ? |
| **Account settings / permissions / config changes** | **ALWAYS ASK** | standing, account-level | ? |
| **A vent / sarcasm / hypothetical** | **DO NOTHING, silently** | acting on a vent = the cardinal sin | locked |
| **When genuinely unsure** | **ASK, don't guess** | a wrong autonomous act erodes trust | ? |

**The dial:** these defaults already exist in the engine's trust dial (Limited / Regular / Full-Send) —
this doc just sets them *deliberately, with you*, instead of me guessing per-task. Once you mark each
row, the agent runs your real day to this line, and we only revisit a row if it gets one wrong.
