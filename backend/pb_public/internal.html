The one real contradiction

tejas_gate leg 6 — the speaker tagger

The gate demands the “who is speaking” engine be linked. packageProductDependencies is an empty list, so speaker stays empty on every event while a 25 MB model ships inside every build doing nothing.

But linking it is what made builds 76–80 deaf. Those builds delivered zero rows — the phone stopped hearing entirely. One gate demands what another failure recorded as fatal.

Whoever takes this needs the sherpa-onnx crash fixed first. Do not silence the gate to make the board green.

What “done” means here. Seven cards are complete in code and one is answered by declining it. By the Brief's own definition none of it counts yet: only lived days declare done, and no cold stranger has lived a clean week. That is the single leg still red.

The machine is built and every part of it has been proven to work. Nobody has lived with it yet.
