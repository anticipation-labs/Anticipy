Three honest things first

  • This is a developer install. Chrome calls it Load unpacked — you download a folder and you keep it, and Chrome reads it from wherever it sits. Move it or delete it and I stop working.
  • It won't update itself. When there's a new version I'll tell you, and you'll download it again and press the refresh arrow on Chrome's extensions page. The Chrome Web Store version, when it's ready, will update on its own.
  • You'll see a yellow bar. While I'm working, Chrome puts a strip across the top of your tabs saying “Anticipy Claude Version started debugging this browser.” That's Chrome being honest that something other than you is clicking. It goes when the task is done.
