  1. Download and unzip

    Download the extension, then double-click the ZIP. Keep the unzipped folder somewhere permanent, such as Documents.

    Download Anticipy

  2. Add it to Chrome

    Open Chrome’s extensions page, turn on Developer mode, choose Load unpacked, and select the unzipped Anticipy folder.

    chrome://extensions

    Chrome does not allow websites to open this settings address for you.

  3. Link your account

    Keep this page open. Your six-digit code appears above as soon as the extension is running. Enter it on the Your computer screen in the Anticipy app.

    The code can link one browser once. Anticipy never asks for your Chrome passwords.

One current limitation: this is a developer install until the Chrome Web Store release is available. Chrome will not update it automatically; a new version means downloading the folder again and pressing the extension’s refresh button.
