machine dictation. Word counts, instruction phrases, numeric patterns and
quotation phrases decided meaning before the model saw the full conversation.
Those overrides are removed. A separate contextual question now returns live
speech, authored content, unclear or unavailable. Only positive authored-content
evidence can suppress the record. A stronger review checks cheap-model vetoes;
missing review does not invent a prohibition. Mixed quoted content and actual
work continue to normal authorship/effect checks. Direct app/text input retains
its known destination.

Adversarial review found that quoted approval could reach a held task before
the destination check. The check now precedes both approval and spoken-answer
paths. The test forbids even calling the release method on authored content.
Prompt injection, mixed quotations, careful speech, numeric references, missing
judgements and strong-model disagreement are covered. No new semantic word rule.

runs now meet their reviewed planning outcomes: seven quiet, five useful private

These runs do not prove execution of those five tasks. Three original harness
results retained an infrastructure flag because background model reservations
were still open when planning stopped; all later returned, recorded separately
in the cost reconciliation. Original files were not overwritten.

change. The maintained addressee/authorship/delivery command passes 106 tests.
