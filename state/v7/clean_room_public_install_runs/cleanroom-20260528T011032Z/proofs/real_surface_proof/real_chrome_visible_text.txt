Agent handoff runbook
For any agent picking up this project
01
1. `cat ralph/memory/state.md` — single source of truth for what's done + what's next.
02
2. `cat docs/PRD.txt` — product spec, do not deviate without recording a decision in ralph/memory/decisions.md.
03
3. `cat CLAUDE.md` — build brief.
04
4. Pick the top item from 'Loop priorities' in state.md. Implement in a thin vertical slice.
05
5. Backend changes → run `cd backend && uv run pytest -q`.
06
6. Frontend changes → run `cd frontend && pnpm run lint && pnpm run build`.
07
7. Both → run `cd frontend && pnpm exec playwright test`.
08
8. `git add -A && git commit -m 'ralph: <one-line>' && git push origin main` to publish.
09
9. If deployed: `cd frontend && vercel deploy --yes --prod` to push the frontend, then PATCH backend env on its host.
10
10. Update `ralph/memory/state.md` with what shipped + new priorities.
