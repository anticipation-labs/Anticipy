# Anticipy Bug Catalog

**Methodology**: Continuous static audit walking 54+ surfaces (pages, API routes, engine modules, scripts).
**Numbering**: B### sequential. Dedup by hash(Surface + Title).
**Severity**: P0 (security/data loss/prod broken), P1 (functional break for users), P2 (poor UX/perf/SEO), P3 (cosmetic/minor).
**Scope**: Catalog only, no fixes.
