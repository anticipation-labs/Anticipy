# factory/wiring_allowlist.txt — the ONLY legitimate exits from factory/bin/check_wiring.py.
#
# FORMAT (tab-separated, one entry per line):
#   KIND<TAB>NAME<TAB>JUSTIFICATION
#   KIND  = endpoint | route | module
#   NAME  = exactly what the gate prints (engine path, /api/... route, or module path
#           relative to engine/anticipy_engine/)
#   JUSTIFICATION = why this is allowed to have no in-repo caller. NEVER empty — an
#           allowlist entry without a reason is just the disease with paperwork.
#
# THE DEBT CONVENTION: a justification starting with "TODO(FIX-NN" is acknowledged DEBT,
# not a blessing. It passes the default run (so the suite stays honest about NEW breakage)
# and FAILS `check_wiring.py --strict` (so the debt can never silently become permanent).
# Everything else is PERMANENT and must name a real out-of-repo caller (a monitor, Twilio,
# a browser typing a URL) — "we'll wire it later" is never a permanent justification.
#
